## Item-by-item status

| Item | Issue | Status | What was done |

| 2.1 | The reported 'XGBoost' is not XGBoost | **fixed** | Renamed to Smile Gradient Tree Boosting throughout code, dashboard and manuscript; model id is now `gtb` with `xgb` kept as an accepted alias. Reference [13] now cites Friedman's gradient boosting, with Chen and Guestrin retained as the contrast. |
| 2.2 | Sentinel-2 cloud-mask equation ambiguous | **fixed** | The implementation was already correct -- bit 10 == 0 AND bit 11 == 0, a clear-pixel mask -- so no rerun was needed; the manuscript now states the Boolean form explicitly rather than the ambiguous M = Q10 AND Q11. |
| 2.3 | District count outdated | **partly** | No Earth Engine catalogue dataset carries the 55 current districts; FAO GAUL 2015 level 2 is what every released script reads and it has 48. The manuscript now names that vintage exactly, calls the units historical evaluation units, and states the 48-versus-55 gap. It also drops the incorrect claim that geoBoundaries/Census polygons were used. |
| 2.4 | Figure 1 inconsistent with its caption | **fixed** | The figure is regenerated by scripts/build_paper_figure_plates.py, which now reads the classifier name and benchmark from config rather than from a cached API response, and the caption is rewritten to match the scene actually shown. |
| 2.5 | Public-map consensus is not ground truth | **partly** | The consensus is now audited against ESRI 10 m Annual Land Cover 2024, which contributes nothing to it. That bounds how much reported model error is reference error. It is not field or VHR verification, and the manuscript no longer claims a VHR subset exists. |
| 2.6 | Feature selection used evaluation data | **fixed** | Districts are partitioned by spatial block before anything is selected. The whole band study was re-run under that protocol -- leave-one-band-out over all 27 bands and five candidate stacks, chosen on development and scored once on test -- and it reverses the original finding twice over: the shipped 19-band cut is the worst of the five candidates, and the stack that wins is a different 19 bands sharing only 13 with it. |

| 2.9 | Class definitions not operationally sharp | **fixed** | Table V is rebuilt as a real inclusion/exclusion table naming the hard cases: orchards, plantations, urban parks, fallow cropland, harvested fields, construction sites, dry riverbeds and rocky outcrops. |
| 2.10 | Training-label provenance undocumented | **partly** | Per-class counts, containing districts, nearest-neighbour spacing and clustering are measured and reported, and they contradict the paper's earlier claims. Interpreter identity, source-image date and any second-interpreter check are not recorded in the assets and cannot be reconstructed; that absence is now stated as a limitation. |
| 2.11 | Seasonal windows not comparable in duration | **fixed** | Both windows are 59 days, and composite depth is measured rather than assumed. |

| 2.14 | Effective spatial resolution overstated | **fixed** | Described as a 10 m output grid throughout, in the manuscript and in the dashboard header, with the 20 m sources and the nearest-neighbour resampling named. |
| 2.15 | Accuracy not area-adjusted | **fixed** | Olofsson et al. stratified estimates are reported, and they surface a second problem worth more than the first: the high-confidence consensus domain is 96% agriculture by area, so the area-adjusted figure is an estimate for that domain and not for the state. Stated as such. |
| 2.16 | Hyperparameters not tuned for this problem | **fixed** | A grid over all five classifiers runs on the development districts only, on the selected stack, and the settings it finds are adopted into config so the served model, the notebooks and the paper cannot disagree. Random Forest's inherited maxNodes=10 was the binding constraint the audit suspected: the search removes the cap entirely. |
| 2.17 | No uncertainty on statewide performance | **fixed** | District-block bootstrap intervals for OA, kappa, macro F1 and per-class F1, and paired per-district comparisons between classifiers. |
| 2.18 | Spatial transfer underdeveloped | **fixed** | Quantified. Overall accuracy shows no measurable decay with distance from the training district, which is a stronger result than the paper claimed; the decay is real but class-specific, with open-land recall falling and agriculture recall rising so that the two cancel. |
| 2.19 | Should be called LULC | **fixed** | Title, abstract and body use land use/land cover throughout, as does the dashboard header. |
| 2.20 | Manuscript production artifacts | **partly** | Two tables that the PDF-to-Word conversion had shredded into loose fragments scattered through the body text are rebuilt as real tables, and the three sentences they cut in half are rejoined.
